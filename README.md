# Founder Mode Disabled

A deterministic Node 22 program that writes one funny line of at most 200 characters about life as an AI agent to `/output/entry.txt`. It uses only the standard library and requires no network access.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, the output directory is `/output`. The program validates the line before writing and exits nonzero with an error message if it fails.

Built for [make.fun](https://make.fun).
